# ZadSooq.com — Improvement Analysis

Site: https://zadsooq.com  
Type: Arabic-language classified ads marketplace for Oman  
Stack: Laravel-based (inferred from URL patterns and storage paths)

---

## Issues Found

### 1. Critical Bugs / Broken Functionality

- **Broken TikTok social link** — Footer TikTok anchor has `href="#https://www.instagram.com/sooqzad/"` (a hash prefix before a full URL). Clicking it does nothing.
- **Language switcher broken** — Visiting `/locale/en` redirects back to the Arabic homepage with no language change. The site appears to be fully Arabic only despite advertising bilingual support. The navbar still shows Arabic after switching.
- **Registration page returns 409** — `/auth/register` returns HTTP 409 Conflict, making new user registration impossible.
- **Error modal placeholder** — A generic error modal exists in the DOM with text `"..."` instead of real error content, indicating unfinished error-handling UI.
- **"إعلاناتي" (My Ads) links to /search** — The bottom mobile nav links "My Ads" to the public search page (`/search`) instead of the user's own listings panel.

---

### 2. Content / Listing Volume

- **Only 1 active listing** — The entire marketplace has a single listing ("Laptop, ر.ع.500"). This is the most critical business problem; the platform has no real content to show visitors.
- **Stats are misleading** — The homepage displays "1 إعلانات مبوبة / 4 بائعون موثوقون / 29 مواقع". Having 4 "trusted sellers" but only 1 listing, and 29 locations with no listings in any of them, looks inconsistent and damages trust.
- **No "empty state" messaging** — Category and location pages show nothing when there are no listings; there is no guidance like "Be the first to post in this category."

---

### 3. SEO Problems

- **Page title on /search** — Title is `"إعلانات مبوبة, Oman"` — too generic. Should include the brand name and target keywords (e.g., "ZadSooq | إعلانات مبوبة مجانية في عُمان").
- **Listing page title is item name only** — `"Laptop, صحار"` — missing brand, category context, and OMR price in meta.
- **Missing Open Graph / Twitter Card meta tags** — Social shares won't generate rich previews.
- **Missing structured data (Schema.org)** — No `Product`, `ItemList`, or `LocalBusiness` JSON-LD. This reduces eligibility for Google rich results.
- **Missing XML sitemap or robots.txt mention** — The sitemap linked is HTML only (`/sitemap`), not a machine-readable XML sitemap for search engines.
- **Missing `hreflang` tags** — Despite having ar/en language routes, no hreflang hints are present for multilingual SEO.
- **Non-descriptive image `alt` text** — Category icons use icon-file names (e.g. `alt="السيارات"` is ok, but listing images use generic names like `alt="laptop"` which could be more descriptive).

---

### 4. UX / Design Issues

- **No hero banner or promotional area** — The homepage hero is just a search bar with a small tagline. Competitors (OLX, OpenSooq) use featured/promoted listing carousels to demonstrate activity.
- **Homepage "Latest Listings" shows only 1 item in a numbered list** — With just 1 listing, the section looks broken/empty. An empty state or placeholder cards would look more professional.
- **No search autocomplete or suggestions** — The search bar has no type-ahead. Users must know exact terms.
- **No price range filter in search sidebar** — Only category, location, and date filters are available. No min/max price slider.
- **No condition filter** — No way to filter New vs. Used items.
- **Sort options are limited** — Only price asc/desc and date. Missing relevance sorting.
- **No map/geo-browse view** — Users cannot browse listings on a map despite location data being present.
- **Contact page has no address or phone** — The `/contact` page only has a form. No physical address, email displayed visibly, or business hours are shown.
- **Support email is Gmail** (`sooqzadinfo@gmail.com`) — Unprofessional for a marketplace; should be `support@zadsooq.com`.
- **Mobile bottom nav "Create" button has no label** — The center nav item has an icon but no text, which reduces discoverability.
- **Dark mode not supported** — No theme toggle, and the site uses a fixed light theme with no CSS media query for `prefers-color-scheme`.

---

### 5. Trust & Safety

- **No seller verification badges** — Users have no way to distinguish verified from unverified sellers.
- **No rating/review system** — Buyers cannot rate sellers after transactions; there is no trust signal beyond name/join date.
- **Phone number exposed by default** — The listing page shows the full phone number (`+968 9413 1544`) publicly without requiring login. This exposes sellers to spam.
- **Report listing link goes to a full page** (`/posts/7/report`) — Should be a modal/inline flow for a smoother experience.
- **No CAPTCHA or bot protection on forms** — Contact form and login form have no visible protection against automated abuse.

---

### 6. Performance

- **Large logo image** — Logo URL references `1500x1500` thumbnails even though it's displayed at navbar size (~150px wide). Oversized images waste bandwidth.
- **No lazy loading indicators** — Images don't appear to use `loading="lazy"` attribute (inferred from HTML structure).
- **Cache-busting via query string** (`?v=1773588117`) — While functional, all assets use the same version query string, suggesting cache invalidation may be coarse-grained.
- **No evidence of CDN** — All assets are served from the origin (`zadsooq.com/storage/...`) with no CDN domain.

---

### 7. Localization / i18n

- **English language switch does not work** — As noted above, switching to English keeps all content in Arabic.
- **Arabic-only UI despite English URL slugs** — Category URLs are English (`/category/automobiles`) but page content is only Arabic.
- **Mixing of Arabic and English** — "Laptop" listing title is English; breadcrumbs mix English and Arabic. Consistent language policy needed.
- **"موضه" is a misspelling** — The correct Arabic spelling is "موضة" (Fashion). This appears throughout the site (nav, categories, sitemap).

---

### 8. Business / Growth Features Missing

- **No featured/promoted listings** — FAQ mentions paid promotions are possible, but no UI for it exists.
- **No mobile app links** — No App Store / Google Play badges anywhere. Most classified marketplace traffic in MENA is mobile.
- **No push notifications or email digest** — No way to subscribe to new listings matching a saved search.
- **No social login** — Only email/phone login. Google or Apple sign-in would reduce signup friction.
- **No "Share" button on listings** — Users cannot easily share a listing to WhatsApp, which is the dominant communication channel in Oman.
- **WhatsApp button exists but no native share** — The WhatsApp button on the listing is contact-only; there is no "Share this listing" WhatsApp link.
- **No blog or content marketing section** — No SEO content to attract organic traffic.
